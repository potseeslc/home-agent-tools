# Contributing

The project is currently in planning and gateway evaluation. Useful contributions include reproducible compatibility findings, design review, and narrowly scoped prototypes tied to the roadmap.

Open an issue describing the problem or proposed change before a large implementation. Use pull requests for changes. Include relevant verification and clearly separate working behavior from proposals.

Use synthetic examples and reserved domains such as `example.com`. Never submit credentials, private inventories, database dumps, personal identity records, or production configuration. Avoid copying an existing private repository or its history into this project.

Keep runtime-specific integrations small and document limitations. Preserve licenses and attribution for reused code. There is no contributor license agreement at this stage; contributions are made under the repository's MIT license.
